# Демо frontend-siemens

`frontend-siemens` - клиентский React-прототип без бэкенда. Он показывает рабочий контур ролей: коммерция, завпроизводство, бухгалтерия, директор, оператор, склад и админ.

## Запуск

```bash
cd frontend-siemens
npm install
npm run dev -- --host 127.0.0.1 --port 5175
```

Открыть: `http://127.0.0.1:5175/`

Прямой вход в роль:

- `/?role=commercial`
- `/?role=production`
- `/?role=finance`
- `/?role=director`
- `/?role=operator`
- `/?role=warehouse`
- `/?role=admin`

Без параметра открывается коммерческий старт потока.

## Рекомендуемый сценарий показа

1. Коммерция: входящая заявка, шаблон клиента, ответственный, передача в заказ-наряд.
2. Завпроизводство: полнота заказ-наряда, отличие от шаблона, передача к счету/решению.
3. Бухгалтерия: счет, статус источника, ошибка синхронизации, рассрочка после выдачи.
4. Директор: главный центр, отчеты по ролям, проблема склада, финансовый риск, причина решения и равноправные действия.
5. Оператор: текущий шаг у станка, весы, блокировка при отсутствии ответа весов, QR, передача на склад.
6. Склад: scan-first приемка, дубль/чужой QR, частичная приемка, выдача.
7. Админ: устройства, привязка рабочего места, справочники, права видимости, диагностика без выполнения чужих ролей.

## Что честно является прототипом

- Нет production-бэкенда, авторизации и реальных прав доступа.
- Нет реального обмена с 1С, весами, сканерами и принтерами.
- Данные зашиты в клиентский demo dataset и нужны для проверки сценариев.
- `?role=` - переключатель демо-ролей, а не production auth.
- Вес в операторском интерфейсе показывается как scale-only: если весы не отвечают, шаг блокируется до восстановления устройства.
